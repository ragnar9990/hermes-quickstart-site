Features

Everything Hermes needs, set up for you.

Setting up Hermes by hand means installing WSL2, picking a Python toolchain, running an interactive shell script, writing a YAML config, registering bot tokens, and wiring up a systemd service. Quickstart does it all in a single flow.

Cross-platform

Native installer for Windows, macOS, and Linux. The same wizard works everywhere.

Auto WSL2

On Windows, Quickstart installs WSL2 + Ubuntu for you, including the admin elevation and reboot handling.

Secure key storage

API keys go straight into your OS keychain. They're never written to disk in plaintext.

Discord, Telegram, Slack

Paste a bot token, the wizard registers the gateway as a systemd service and walks you through the post-install Discord intents step.

Five providers, ready

OpenRouter, Nous Portal, Anthropic, OpenAI, NVIDIA NIM — pick one in the wizard, paste a key, done. Or pick a custom model.

MIT, free, forever

The installer is free. Hermes Agent itself is MIT-licensed and open source, maintained by Nous Research.

How it works

From download to chatting in under five minutes.

  1. 01

    Download & launch

    One installer per OS. Open it — no admin tricks, no command-line preflight.

  2. 02

    Pick a provider

    Choose your LLM provider, paste an API key (with per-provider step-by-step links), pick a model.

  3. 03

    Wire up chat platforms (optional)

    Toggle Discord, Telegram, or Slack. Paste each bot token. The wizard registers the gateway service and gives you an invite link.

  4. 04

    Watch it install

    Live progress bar, plain-English status, and full streaming log. Quickstart handles dependencies, the Hermes install script, and the systemd unit.

Is this affiliated with Nous Research?

No. Hermes Agent is an open-source project by Nous Research; this installer is an unofficial wrapper that makes setup easier. All credit for the agent itself goes to them.

Is it safe to paste my API keys?

Keys go directly into your OS keychain via keytar. They're never written to a flat config file by Quickstart, and they're injected into Hermes's environment only at install time.

What if I already have Hermes installed?

Quickstart detects an existing install and re-runs the configuration steps idempotently — useful for switching providers or adding a new chat platform without starting over.

Source code?

Quickstart is open source under the MIT license. Issues, PRs, and forks are welcome. Hermes Agent's source lives at the official Nous repo.
